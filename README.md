# Ghazni Open Library

Ghazni Open Library is an open-source, non-commercial educational project that collects research, sources, and reference materials on the history and culture of Ghazni province, Afghanistan, and the Ghaznavid civilization. It is built to be freely accessible and openly maintained, with contributions welcomed from researchers, translators, and the public.

## About the Project

Much of this material currently exists only in fragmented academic sources, private collections, or is not digitized at all, making it hard for students, researchers, and the diaspora to access. Ghazni Open Library gathers this scattered historical, cultural, and archival research into a single, publicly accessible digital library.

The project is released under the MIT License so that its code and structure remain free for anyone to use, adapt, or build on. We actively invite community contributions — sources, translations, corrections, and technical improvements — through this public repository.

The site is hosted on Netlify, which supports reliable, ongoing public access to the archive as it grows.

## Goals

- Preserve and centralize research about Ghazni and the Ghaznavid civilization
- Make historical and cultural materials freely and openly accessible
- Enable community contributions from researchers, translators, and the public
- Maintain the archive as a lasting, public-interest educational resource

## Contributing

Contributions of sources, translations, corrections, and technical improvements are welcome. Please read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request, and review our [Code of Conduct](CODE_OF_CONDUCT.md).
