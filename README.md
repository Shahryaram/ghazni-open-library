# Ghazni Open Library

An open, public, and collaborative digital library and research hub for the history, culture, and civilization of Ghazni province, Afghanistan — including the Ghaznavid civilization.

## Mission

To gather scattered research, sources, references, and learning materials about Ghazni into one open, freely accessible place — and to keep building it publicly, with anyone who wants to contribute.

## Background

This project began with a simple, personal experience. I was born during wartime in Ghazni province. As a child, I went looking for a library and found only the ruins of what had once been a public one. A guard there told me I was the first person who had ever asked about it. That memory stayed with me. This project is an attempt to build, in digital form, something like what was lost — a public library for Ghazni that anyone, anywhere, can read from and add to.

## Founder Note

This project is rooted in a personal commitment to public access to knowledge. Growing up in Ghazni, Afghanistan, I became deeply aware of how fragile access to books, research, and public memory can be. This open library is my effort to help preserve and share knowledge about the region in a way that is public, collaborative, and accessible to others.

## What This Project Does

Ghazni Open Library brings together:

- Historical and cultural research and references related to Ghazni and the Ghaznavid civilization
- Links to existing academic, archival, and public-domain sources
- Organized bibliographies and reading lists
- Space for translations between languages (e.g., Pashto, Dari, English)
- Notes on research gaps — topics that are under-documented and need more work

Over time, the project may also grow to include:

- AI-assisted summaries of existing research (clearly labeled as such)
- Podcast-style educational audio
- Short animations or explainer videos
- Children's or general-audience educational materials

The website itself is a static site, and this repository contains its source code along with the documentation needed to run, maintain, and contribute to it.

## Why It Matters

Ghazni's history and culture are not well documented in any single, accessible place. What exists is scattered across books, archives, academic journals, and private collections — much of it hard to find, especially for people inside Afghanistan or in the diaspora who want to learn about their own history. This project exists to lower that barrier: to collect what already exists, make it easier to find, and create an open structure where more people can add to it over time.

## Main Features

- A browsable, organized collection of research and reference material
- Bilingual/multilingual support as content grows
- A simple, transparent structure that's easy for new contributors to understand
- Fully open source — anyone can read, copy, modify, or build on this project

## Educational and Non-Commercial Purpose

This project is educational and archival in nature. It is not created or operated for commercial purposes. It exists to preserve and share knowledge, and it is released under an open-source license so that its content and code remain freely available to the public.

## Project Status

This project is in an early, active stage. The core website structure exists, and the focus right now is on:

- Organizing and expanding the source collection
- Setting up a clear contribution process
- Establishing the open-source repository and documentation (this README, license, contribution guide, and code of conduct)

Expect the structure and content to change as the project grows.

## Roadmap

- Publish the initial open-source repository and website
- Build out a structured bibliography/sources section
- Open a clear process for community-submitted sources and corrections
- Add translation support for key content (Pashto, Dari, English)
- Identify and document research gaps
- Explore AI-assisted summaries of existing research (clearly labeled, with sources)
- Explore podcast-style and short-video educational content
- Explore accessible materials for younger or general audiences

This roadmap will evolve. Suggestions and priorities from contributors are welcome.

## Deployment

The site is hosted on Netlify and connected to this repository for continuous deployment. Any change merged into the `main` branch is automatically built and published to the live site.
